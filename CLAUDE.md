# time-to-go

## Docs language policy

Docs under `docs/` are maintained in two languages:

- `docs/en/` — English. Source of truth — read and edit this when working on docs content.
- `docs/ko/` — Korean translation, kept in sync with `docs/en/`.

When a doc changes, update `docs/en/` first, then mirror the change into `docs/ko/`.
