# Personas

Grounded in the one action the product supports: enter a start place, an end
place, and an arrival deadline; get back a departure time and a transit route.

## 1. The deadline commuter

Has somewhere to be — work, an interview, a class — and one fixed arrival
time that isn't negotiable. Doesn't care about route options or scenic
choices, just the latest safe moment to walk out the door. Checks the app
right before leaving, not while planning the day in advance.

**Needs:** a single trustworthy departure time, fast. Wrong or stale transit
data is worse than no answer.

## 2. The unfamiliar-area visitor

Meeting someone (an appointment, a first date, a friend) in a part of the
city they don't commute through regularly. Knows the destination's name but
not the transit line, transfer points, or how long it actually takes to get
there.

**Needs:** the route itself, not just the time — which bus/subway, which
transfers, so they don't get lost mid-trip.

## 3. The margin planner

Building in buffer on purpose — doesn't want to arrive at the last possible
minute. Runs the calculation, then mentally adds 10–15 minutes of slack
before deciding when to actually leave.

**Needs:** a departure time to treat as a floor, not a target — accuracy
matters more than an optimistic estimate.
